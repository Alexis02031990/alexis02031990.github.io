## 🎓 INFORMATIONS TECHNIQUES

### Gradients CSS Appliqués
```css
/* Crée un dégradé de couleur sur le texte */
background: linear-gradient(135deg, #couleur1 0%, #couleur2 100%);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;
background-clip: text;
```

### Hover Effects
```css
/* Élévation de la carte */
transform: translateY(-5px);

/* Zoom du logo */
transform: scale(1.1);

/* Ombre au survol */
box-shadow: 0 15px 50px rgba(0,0,0,0.3);
```

### Responsive Breakpoints
```css
/* Desktop */
1280px+ : Layout optimal, logo 60px

/* Tablet */
768px - 1279px : Design adapté

/* Mobile */
<768px : Logo 50px, menu burger
```
