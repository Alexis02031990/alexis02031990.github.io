## 🛠️ Besoin d'Aide ?

### Le serveur ne fonctionne pas ?
```powershell
# Vérifier que le serveur fonctionne :
# Si le port 8000 est occupé, utilisez :
netstat -ano | findstr :8000
# Puis terminez le processus et redémarrez
```

### Les logos ne s'affichent pas ?
1. Ouvrir DevTools (F12)
2. Aller à l'onglet "Network"
3. Chercher les fichiers `logo-*.jpg` ou `logo-*.png`
4. S'ils sont en 404, vérifier les chemins HTML

### Les couleurs ne s'affichent pas ?
1. Ouvrir DevTools (F12)
2. Faire Ctrl+Maj+R (Hard Refresh)
3. Chercher des erreurs CSS dans la Console
