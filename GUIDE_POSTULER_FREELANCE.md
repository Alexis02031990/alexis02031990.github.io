## 2️⃣ CHERCHER MISSIONS SUR MALT (10 minutes/jour)

### Accès missions
- 🌐 https://www.malt.fr/s/tags/as400
- Ou chercher : "rpg", "ibm i", "as400"

### Filtrer résultats
1. Cliquer "Filtrer"
2. Sélectionner :
   - Type : Missions courtes / moyennes
   - Budget : 400€+ par jour
   - Domaine : IT / Développement

### Pour chaque mission
```
1. LIRE attentivement la description
2. VÉRIFIER que vous match le profil
3. PROPOSER votre tarif (450-500€/j min)
4. ÉCRIRE un message court personnalisé :

   Exemple :
   "Bonjour,
   Développeur AS/400 / IBM i avec 2+ ans d'expérience.
   Excellente maîtrise de RPG, CL et SQL.
   Expérience récente chez Toyota et NOTOS.
   Intéressé pour cette mission sur [technologie demandée].
   Tarif : 450 €/jour | Disponible immédiatement.
   Portfolio : [lien]"
```

### Conseils
- ✅ Répondre dans les 2 heures (meilleur taux réponse)
- ✅ Être précis et court
- ✅ Inclure lien portfolio
- ✅ Montrer que vous avez lu la mission

## 3️⃣ PORTAGE SALARIAL : PROCESSUS

### Choisir une société
**Recommandation pour vous : OPENWORK**
- 🌐 https://www.openwork.fr
- Frais : 5% (très compétitif)
- Service : Premium avec accompagnement
- Note : 4.2/5

Ou **JUMP** si budget plus serré

- 🌐 https://www.jump.jobs

### Candidature
1. Aller sur site portage salarial
2. Cliquer "Rejoindre" / "Candidater"
3. Remplir le dossier :
   - Identité, coordonnées
   - CV (utiliser votre CV Word)
   - Lettre motivation (2-3 lignes)
   - Domaines d'expertise (AS/400, RPG, etc.)
   - Tarif souhaité : 450-500€/jour

### Documents à préparer
- ✅ Pièce identité
- ✅ Justificatif de domicile
- ✅ CV (PDF/Word)
- ✅ Relevé bancaire

### Délai
- Réception dossier : 1-2 jours
- Vérification : 3-5 jours
- Acceptation : Validation par société

### Après acceptance
- Vous recevez identifiants
- Accès à portail missions
- Support dédié pour candidatures

## 📊 STRATÉGIE DE CANDIDATURE OPTIMALE

### Semaine 1
- Lun : Créer profil Malt
- Mar : Poster 5 missions Malt
- Mer : Candidater portage salarial
- Jeu : Chercher offres Indeed (5 candidatures)
- Ven : Envoyer candidatures spontanées (3 emails)

### Semaine 2
- Lun-Ven : 2-3 candidatures/jour Malt
- Lun-Ven : Lire réponses et relancer si besoin
- Fin semaine : Upwork (5 proposals)

### Semaine 3+
- Continuer Malt quotidiennement
- Relancer après 3 jours si pas de réponse
- Accepter premières missions
- Augmenter visibilité
