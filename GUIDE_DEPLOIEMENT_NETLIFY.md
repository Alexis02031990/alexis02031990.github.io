## 📋 INSTRUCTIONS PAS A PAS

### **ETAPE 1: Créer un compte Netlify** (1 min)

1. Allez sur: **https://www.netlify.com**
2. Cliquez **"Sign up"** (en haut à droite)
3. Choisissez **"Sign up with GitHub"**
4. Autorisez Netlify à accéder à votre GitHub
5. Validez

### **ETAPE 2: Connecter votre repo GitHub** (30 secondes)

1. Après connexion, cliquez **"New site from Git"** (gros bouton)
2. Sélectionnez **GitHub** comme provider
3. Trouvez et sélectionnez: **alexis02031990.github.io**
4. Cliquez **"Deploy site"**

### **ETAPE 3: Configuration (laissez les defaults)** (10 secondes)

Netlify va automatiquement :
- ✅ Détecter votre site
- ✅ Configurer le déploiement
- ✅ Lancer la production

**VOILA ! Votre site est en ligne ! 🎉**
