## 💾 COMMENT UTILISER

1. **Copier le template** qui vous convient
2. **Personnaliser** avec :
   - Nom recruteur / entreprise
   - Spécificités de l'offre
   - Votre numéro téléphone
3. **Vérifier** orthographe et liens
4. **Envoyer** via plateforme ou email

## 🎓 PRO TIPS

✅ **Toujours inclure** :
- Lien portfolio
- Tarif minimum
- Disponibilité
- Référence (Toyota, NOTOS)

✅ **Adapter** chaque message à l'offre :
- Lire bien l'offre
- Mentionner leur technologie spécifique
- Montrer que vous avez compris le besoin

❌ **Ne jamais** :
- Copier-coller générique (très visible)
- Oublier lien portfolio
- Proposer moins de 450€/j
- Envoyer après 24h
