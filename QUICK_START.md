## 🔧 Troubleshooting Rapide

### Ça ne marche pas
1. Vider le cache (Ctrl+Shift+R)
2. Vérifier la console (F12)
3. Lire README_DESIGN.md section "Dépannage"

### Mobile n'est pas responsive
1. Vérifier que le fichier CSS est chargé
2. Redimensionner la fenêtre ou tester sur vrais appareils
3. Consulter TEST_CHECKLIST.md

### Couleurs ne changent pas
1. Modifier les variables CSS dans `:root`
2. Vider le cache (Ctrl+Shift+R)
3. Recharger la page
