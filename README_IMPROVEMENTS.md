## 🔧 Support Technique

### Le Portfolio ne S'affiche Pas Correctement ?
1. Vérifiez que `styles-enhanced.css` existe dans le dossier `css/`
2. Rafraîchissez le navigateur (Ctrl+Shift+R)
3. Vérifiez la console du navigateur (F12) pour les erreurs
4. Assurez-vous que tous les fichiers HTML incluent le lien CSS

### Les Couleurs Ne Changent Pas ?
1. Vérifiez que vous modifiez le bon fichier : `css/styles-enhanced.css`
2. Assurez-vous que la syntaxe CSS est correcte (`:` et `;`)
3. Rafraîchissez le navigateur
4. Vérifiez le cache du navigateur

### Les Animations Ne Fonctionnent Pas ?
1. Vérifiez que CSS est chargé (F12 → Styles)
2. Désactivez les extensions du navigateur
3. Essayez un autre navigateur
4. Vérifiez que `styles-enhanced.css` est bien lié
